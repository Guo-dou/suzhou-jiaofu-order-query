# 苏州交复文件管理查询 — 项目说明

> 版本：v1.0（最终版） ｜ 开发者：黄杰 ｜ 适用系统：Windows 10/11

一个按 **3DP 订单** 快速定位并打开对应订单文件夹的桌面小工具，数据来自苏州交复工作跟进表。

---

## 一、功能总览

| 功能 | 说明 |
|---|---|
| 订单查询 | 支持按 **订单号**（完整/部分/不区分大小写）、**客户名称**、**患者姓名（数据名称）** 实时模糊搜索，结果最多显示 200 条 |
| 一键打开文件夹 | 选中订单后按 **回车** 或 **双击** 或点 **打开文件夹** 按钮，直接打开该订单在磁盘上的文件夹 |
| 数据路径自选 | 数据根目录 + 跟进表文件均可自行选择，保存到 config.json，换机器/换路径后自动重新引导选择 |
| 7 列订单列表 | 订单编号 / 订单类型 / 客户 / 产品类型 / 数据名称 / 当前状态 / 接单时间 |
| 列宽智能适配 | 首次启动按每列最长内容自动调整列宽；也支持**手动拖动表头分隔线**调宽，并**记住设置**，下次启动沿用 |
| 订单详情 | 窗口底部显示选中订单的 8 项详情（订单号/客户/产品类型/数据名称/当前状态/机型/材料/快递单号）+ 文件夹路径 |
| 无弹窗设计 | 打包为 exe 后无黑色控制台窗口，全程纯图形界面 |
| 高清图标 | 多尺寸高清图标：小尺寸（16-48px）为"交"字，大尺寸（64px+）为完整"苏州交复"字样 |

## 三、使用方法

### 给别人分发
1. 只发送 **`苏州交复文件管理查询.exe`** 一个文件即可（无需任何依赖）。
2. 对方首次运行：程序检测不到有效数据路径时，会自动弹出"设置数据路径"窗口，选择：
   - ① 数据根目录（存放 01 侧弯订单 ~ 05 医学模型 文件夹的目录）
   - ② 工作跟进表文件（.xlsx，需含"订单跟踪"工作表）
3. 之后每次启动自动加载。

> ⚠️ 无签名 exe 首次运行可能被 Windows SmartScreen 拦截：点"更多信息 → 仍要运行"。个别杀毒软件可能误报，加信任即可。

### 本机使用
- 双击 `启动苏州交复文件管理查询.bat` 或直接运行 exe。
- 程序目录下自动生成/读取 `config.json`，保存路径与列宽设置。

## 四、数据与目录结构约定

程序依赖以下结构（数据根目录下）：

```
数据根目录
├── 01 侧弯订单
│   ├── 交复侧弯订单管理\ 客户名\ 订单号   (3DP-101 前缀)
│   ├── 固定支具订单管理\ ...              (3DP-104 前缀)
│   └── 0售后件\ ...
├── 02 鞋垫订单\ 订单管理\ ...             (3DP-102 前缀)
├── 03 头枕订单\ ...                       (3DP-103 前缀)
├── 04 服务订单
└── 05 医学模型\ ...                       (3DP-105 前缀)
```

- 订单号格式：`3DP-XXX-YYYYMMDD-NNN`（按此格式在磁盘扫描、Excel 过滤）
- Excel 跟进表要求：存在"订单跟踪"工作表，且列结构为苏州交复标准表（至少 36 列；订单号=第1列、客户=第3列、产品类型=第5列、数据名称=第6列、当前状态=第37列 等）
- 表结构不符时程序会给出明确中文提示（缺工作表/列数不足）

## 五、重新开发 / 重新打包

### 环境
- Python 3.14 + PyInstaller 6.22 + openpyxl（读取跟进表）
- 打包命令（在项目目录下执行）：

```powershell
python -m PyInstaller --onefile --noconsole --name "苏州交复文件管理查询" `
  --icon "绝对路径\icon.ico" `
  --add-data "绝对路径\icon.ico;." `
  --distpath .\dist --workpath .\build --specpath .\build --clean order_opener.pyw
```

### 重新生成图标
```powershell
python make_icon.py   # 生成 icon.ico（7 尺寸）与 icon.png
```

### 源码自测
```powershell
python order_opener.pyw --selftest   # 数据层自检（读取/扫描/搜索）
pythonw order_opener.pyw             # 图形界面运行
```

## 六、config.json 配置说明

```json
{
  "root": "<数据根目录，如 D:/公司/苏州交复>",          // 数据根目录
  "xlsx": "<跟进表完整路径，如 D:/公司/苏州交复/苏州交复工作跟进表-YYYYMMDD.xlsx>",  // 跟进表
  "col_widths": { "oid": 290, "otype": 95, ... }  // 手动调整过的列宽（可选，自动生成）
}
```

- 路径失效时程序自动弹出重新选择，无需手动改文件。
- `col_widths` 由用户拖动列宽后自动保存，删掉即可恢复"按内容自适应"。

## 七、故障排查

| 现象 | 处理 |
|---|---|
| 程序双击没反应 | 看程序目录下是否生成 `error.log`，把该文件发给开发者（程序运行异常会自动写入） |
| 打开文件夹提示"未找到" | 该订单文件夹可能尚未创建（新订单），或客户名与表格不一致；提示框中会给出预期路径 |
| 图标没变/模糊 | Windows 图标缓存：重启电脑或重新固定到任务栏 |
| 搜索无结果 | 确认输入的是订单号、客户名或患者姓名之一 |
